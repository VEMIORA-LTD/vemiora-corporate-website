# VEMIORA Corporate Website

The official corporate website for VEMIORA LTD.

## Requirements

- Node.js 22 or later
- npm

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in a browser.

## Production check

```bash
npm run lint
npm run build
```

## Production hosting

The project is a standard Next.js application and can be deployed to any host
that supports Node.js applications. Configure the production domain and email
services with the selected hosting provider before launch.

No deployment is performed automatically from this repository.
